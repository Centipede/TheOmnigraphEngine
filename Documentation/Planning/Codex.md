# Codex Screen

**Status June 9th 2026: Early planning begun**


## Functionality

This screen provides several modes meant to work with sections and subsections, which span the entire book.

### Mode: Edit (sections)
- Add new sections
- Edit existing sections
- Delete existing sections

Known subsections can be added to selected sections by simply selecting all
sections in the viewer and invoking a tool that can add named subsections.
